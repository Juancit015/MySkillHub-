## Overview

Superpowers is Jesse Vincent (obra)'s implementation of a full software development methodology that lives inside your coding agent. Instead of the agent jumping straight into code, it is forced to follow mandatory workflows built from 14 composable skills: brainstorm before implementation, write a plan, develop driven by subagents, debug systematically, request and receive code review, finish branches cleanly.

This is the repo with the most stars in this catalog (272k+), and arguably the one that best demonstrates what "a skill" can scale into.
